# Python 装饰器

装饰器本质是一个函数：它接收一个函数，返回一个新函数（包装后的版本）。
典型用途：给函数加日志、计时、权限检查，而不修改原函数代码。

## 最简单的装饰器

```python
def my_decorator(func):
    def wrapper():
        print("调用前")
        func()
        print("调用后")
    return wrapper

@my_decorator
def hello():
    print("hello")
```

`@my_decorator` 等价于 `hello = my_decorator(hello)`。

## 装饰器怎么读

从内向外读：装饰器先执行内层，再逐层向外包装。
